This page lists the public sources that this guide uses. The links go to public
X12 material and CMS program documentation. The licensed 005010X279A1
implementation guide remains the normative source for complete grammar and
situational requirements.

## X12 standards and public interpretations

| Source | Use in this guide |
| --- | --- |
| [X12-X279-PRODUCT](https://ecommerce.x12.org/products/health-care-eligibility-benefit-inquiry-and-response-005010-x279) | Identifies the licensed 270/271 X279 product and where to obtain it. |
| [X12-EXAMPLES-005010X279](https://x12.org/examples/005010x279) | Provides public 270/271 interchange, hierarchy, subscriber and dependent, and `AAA` examples. |
| [X12-RFI-1498](https://x12.org/resources/requests-for-interpretation/rfi-1498-trailing-delimiters-and-999) | Interprets trailing delimiters and named `999` errors for the case described. |
| [X12-RFI-1585](https://x12.org/resources/requests-for-interpretation/rfi-1585-reporting-multi-isas-999) | Supports multiple interchanges in one physical file and separate acknowledgment scope. |
| [X12-RFI-2821](https://x12.org/resources/requests-for-interpretation/rfi-2821-eb01-code-use-aaa-270271) | Explains `EB` and `AAA` use in the case that the Request for Interpretation (RFI) describes. |
| [X12-RFI-2628](https://x12.org/resources/requests-for-interpretation/rfi-2628-msg-segment-271) | Explains `MSG` use in the case that the RFI describes. |
